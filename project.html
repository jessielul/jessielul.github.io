Carousel concept: enrolling at ANU for the first time

A nine-slide carousel that takes new coursework students from offer to enrolled: getting a USI, choosing courses, logging in to ANUHub, adding courses, key dates and where to get help. I condensed the university’s enrolment page into short, numbered steps, with a consistent layout and a progress bar so each slide can be read in a few seconds on a phone. App concept: ANUHelper

A clickable prototype for a student help app that puts common tasks in one place: enrolling for the first time, resetting a password, dropping or swapping a course and paying fees. Each task opens as short numbered steps with key dates, multi-step tasks track your progress, and a “Still stuck?” button leads to the Student Hubs’ contact details. A self-initiated concept, not an official ANU app.
